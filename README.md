# Wedding Invitation (Next.js)

## Run
    npm install
    npm run dev        # http://localhost:3000

## Edit for a new wedding
Open `invitation.config.ts`. All names, date, venue, map link, WhatsApp number and colours are there.
Preview another colour theme without editing: `/?theme=emerald` or `/?theme=navy`.

## Deploy
Push to GitHub and import the repo on vercel.com (no settings needed), or run `npm run build && npm start`.
